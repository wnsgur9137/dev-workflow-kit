# 🛡️ 보안 툴킷 (security 플러그인 설계)

상위: [[Home]]

앱·웹 사이드 프로젝트의 보안 점검을 **Claude Code 안에서** 실행하기 위한 로컬 보안 툴킷 설계 문서.

> [!summary] 한 줄 요약
> **Claude = 해석·수정 제안**, **결정적 오픈소스 스캐너 = 탐지**.
> 모든 스캐너는 로컬 Docker에서 **네트워크 격리** 상태로 실행하고, 외부 통신은 사용자가 명시적으로 실행한 업데이트뿐이다.
> 배포는 **`dev-workflow-kit` 레포의 `security` 플러그인**으로 한다. → [[레포 통합 계획]]

> [!info] 문서 위치
> `dev-workflow-kit/docs/security/` — 저장소 전체 문서 허브는 [[Home]]. 레포 단위 결정(플러그인 구조, 이름)과 통합 계획은 `docs/project/`에 있다.
