# 시크릿 처리

상위: [[보안 툴킷]] · 관련: [[Gitleaks]], [[리포트 포맷]]

## 1. 점검 대상에서 발견된 시크릿
| 단계 | 처리 |
|---|---|
| 탐지 | Gitleaks `--redact` 강제 → raw 리포트에도 원문 없음 |
| 정규화 | `normalize.py`가 모든 도구 evidence에 시크릿 패턴 재마스킹 (MobSF·Semgrep 결과에도 키가 포함될 수 있음) |
| Claude 전달 | 마스킹된 `summary.md`만. 위치(파일:라인)와 종류만 알려줌 |
| 대응 안내 | 폐기(rotate) → 코드에서 제거 → 히스토리 정리(사용자 확인 후) |

> [!warning] Claude가 원본 파일을 열면
> 수정 제안을 위해 Claude가 해당 소스 파일을 열면 원문이 컨텍스트에 들어간다. SKILL.md에서 **시크릿 탐지 라인은 파일 전체를 읽지 말고 위치만으로 수정 제안**하도록 지시하고, 이미 노출된 키는 폐기를 전제로 한다.

## 2. 툴킷 자체 시크릿
| 항목 | 저장 위치 | 비고 |
|---|---|---|
| MobSF API 키 | `~/.config/dev-workflow-kit/security/.env` (권한 600) | 최초 실행 시 생성 (`openssl rand -hex 32`) |
| 그 외 | 없음 | 유료 API 키 불필요 ([[요구사항]] NFR-1) |

- 플러그인 폴더 밖에 두므로 플러그인 업데이트·레포 커밋과 무관 → [[ADR-006 플러그인 마켓플레이스 구조]]
- `.env`는 Claude가 읽지 못하도록 deny → [[Claude Code 권한 정책]]
- 레포에는 예시 파일 `plugins/security/examples/toolkit.env.example`만 커밋

## 3. 워크플로 플러그인 관련
- GitHub MCP 토큰은 환경변수(`GITHUB_PERSONAL_ACCESS_TOKEN`)로만 주입, `.mcp.json`은 레포에서 제외하고 `examples/mcp.json.example`만 커밋 → [[레포 통합 계획]] D6

## 4. 리포트 보관
- 리포트는 `~/.local/share/dev-workflow-kit/security/reports/` — 레포 밖이므로 실수로 커밋될 수 없음
- 30일 지난 run 삭제 (`$PLUGIN/scripts/cleanup.sh`, 스캔 시 자동)
