# 시크릿 처리

상위: [[보안 툴킷]] · 관련: [[Gitleaks]], [[리포트 포맷]]

## 1. 점검 대상에서 발견된 시크릿
| 단계 | 처리 |
|---|---|
| 탐지 | Gitleaks `--redact` 강제 → raw 리포트에도 원문 없음 |
| 정규화 | `normalize.py`가 모든 도구 evidence에 시크릿 패턴 재마스킹 (MobSF·Semgrep 결과에도 키가 포함될 수 있음) |
| Claude 전달 | `summary.md` → 필요할 때만 `findings.json` → 의심스러울 때만 `raw/` (아래). 사용자에게는 위치(파일:라인)와 종류만 알려줌 |
| 대응 안내 | 폐기(rotate) → 코드에서 제거 → 히스토리 정리(사용자 확인 후) |

Claude 가 읽는 순서 (`skills/scan-code/SKILL.md`):
- 마스킹된 `summary.md`를 먼저 읽는다.
- summary에 없는 세부가 필요할 때만 `findings.json`(같은 마스킹 적용)을 연다.
- 정규화 결과가 의심스러울 때만 `raw/`를 연다. Gitleaks는 `--redact`, Semgrep 시크릿 규칙의 근거는 고정 문구로 대체되어 raw에도 원문이 없다.
- 리포트 폴더 전체에 시크릿 원문이 없는지는 E2E 테스트가 `grep -rF`로 검사한다.

> [!warning] Claude가 원본 파일을 열면
> 수정 제안을 위해 Claude가 해당 소스 파일을 열면 원문이 컨텍스트에 들어간다. SKILL.md에서 **시크릿 탐지 라인은 파일 전체를 읽지 말고 위치만으로 수정 제안**하도록 지시하고, 이미 노출된 키는 폐기를 전제로 한다.

## 2. 툴킷 자체 시크릿
| 항목 | 저장 위치 | 비고 |
|---|---|---|
| MobSF API 키·Django 비밀값·관리자 비밀번호 | **저장하지 않음** — `scan-app.sh`가 실행마다 `/dev/urandom`으로 만들어 환경변수로만 넘긴다 | MobSF 가 기동 로그에 API 키를 찍으므로 고정 키를 두지 않는다. 툴킷 로그(`raw/*.log`)에서는 `[MASKED]`로 바꾼다 (P2 구현에서 `.env` 계획을 바꿈) |
| 그 외 | 없음 | 유료 API 키 불필요 ([[요구사항]] NFR-1) |

- 플러그인 폴더 밖에 두므로 플러그인 업데이트·레포 커밋과 무관 → [[ADR-006 플러그인 마켓플레이스 구조]]
- `.env`는 Claude가 읽지 못하도록 deny → [[Claude Code 권한 정책]]
- 레포에는 예시 파일 `plugins/security/examples/toolkit.env.example`만 커밋 (현재 설정 항목 없음)
- MobSF 리포트에는 앱에서 뽑은 시크릿 원문(`secrets`)·문자열 덤프(`strings`)가 들어 있다 — 원본은 정규화 직후 지우고 정제본만 `raw/mobsf.json`에 남긴다 → [[MobSF#raw 보관본]]

## 3. 워크플로 플러그인 관련
- GitHub MCP 토큰은 환경변수(`GITHUB_PERSONAL_ACCESS_TOKEN`)로만 주입, `.mcp.json`은 레포에서 제외하고 `examples/mcp.json.example`만 커밋 → [[레포 통합 계획]] D6

## 4. 리포트 보관
- 리포트는 `~/.local/share/dev-workflow-kit/security/reports/` — 레포 밖이므로 실수로 커밋될 수 없음
- 30일 지난 run 삭제 (`$PLUGIN/scripts/cleanup.sh [--days N] [--dry-run]`, 스캔 시 자동 — `common.sh` 의 `sec_new_run`)
  - 나이는 폴더 이름의 시각(`YYYYMMDD-HHMMSS-<code|app|web>[-n]`, 로컬 시각)으로 정한다. 수정 시각은 복사·백업으로 바뀌므로 쓰지 않는다
  - 이 형식에 맞는 실제 폴더만 지운다. 링크·파일·다른 이름(사용자가 둔 메모 등)은 건드리지 않고, 폴더 안의 링크는 따라가지 않는다. `reports` 자체가 링크면 거부한다
  - 자동 정리가 실패해도 스캔은 계속하고 경고만 낸다
