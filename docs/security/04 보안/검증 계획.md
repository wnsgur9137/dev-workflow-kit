# 검증 계획

상위: [[보안 툴킷]] · 관련: [[구현 계획]], [[업데이트 절차]]

## V1 네트워크 차단
| 테스트 | 방법 | 기대 결과 |
|---|---|---|
| N0 컨테이너 | 각 이미지에서 `curl https://example.com` 또는 동등 명령 | 실패 |
| N1 MobSF | mobsf 컨테이너에서 외부 접속 시도 | 실패 — `test_real_n1_mobsf_is_internal_only`(IP·DNS 차단, 내부 이름은 풀림) |
| N1 호스트 노출 | 호스트에서 `curl localhost:8000`, `PortBindings`·`NetworkSettings.Ports`, 네트워크 `Internal` | 연결 없음 — 같은 테스트 |
| N2 허용목록 외 | ZAP 컨테이너에서 허용목록 밖 URL 요청 | 프록시 403 + 로그 — `test_real_n2_proxy_enforces_allowlist_and_blocks_bypass`(같은 호스트 다른 포트·외부 도메인), 스캔마다 `scan-web.sh` 격리 확인 |
| N2 프록시 우회 | 프록시 설정 없이 직접 요청 | 실패 — 같은 테스트(대상 호스트·외부 IP 직접 연결) |
| 실측 | **LuLu**(무료 macOS 방화벽)로 스캔 1회 전체 동안 Docker 외부 연결 기록 | 업데이트 외 연결 없음 |

> macOS의 Docker 런타임은 VM을 경유하므로 LuLu에는 컨테이너가 아니라 VM 프로세스(Docker Desktop은 Docker 프로세스, Colima는 Lima·VZ 프로세스)로 보인다. 컨테이너 단위 확인은 위 테스트로, 전체 확인은 LuLu로 이중 검증.

### LuLu 실측 절차 (사람이 수행 — P4)
자동 테스트는 컨테이너 단위로 격리를 확인한다. LuLu 실측은 "툴킷 전체가 스캔 중에 밖으로 나가지 않는다"를 호스트에서 한 번 더 본다. GUI 방화벽이라 사람이 지켜봐야 한다.

1. 준비
   - [LuLu](https://objective-see.org/products/lulu.html)를 설치하고 **Alert 모드**(새 연결마다 묻기)로 둔다. 실측 전에 기존 규칙에서 Docker·Colima(Lima·VZ)·`com.docker.*` 를 "허용" 으로 둔 항목이 있으면 잠시 지우거나 꺼 둔다 — 그래야 연결 시도가 경고로 보인다
   - **먼저 `update.sh` 를 끝낸다**(이미지·규칙·OSV DB·egress-proxy 빌드). 실측 중에 이것이 돌면 정상적인 외부 연결이 섞인다
   - 점검할 대상: 작은 테스트 저장소(scan-code), 테스트 APK(scan-app), 로컬 개발 서버(scan-web, `http://host.docker.internal:<포트>` 를 허용목록에 넣음)
2. 기록하며 실행 — 각 스캔을 하나씩 실행하고, 그동안 LuLu 경고·로그를 기록한다
   - `scan-code.sh <저장소>` → 예상: **외부 연결 없음**
   - `scan-app.sh <APK>` → 예상: **외부 연결 없음**
   - `scan-web.sh http://host.docker.internal:<포트>/` → 예상: **호스트의 대상 서버 포트로 가는 연결만**. 인터넷 주소로 가는 연결 없음
3. 판정
   - 통과: 위 예상 밖의 연결 시도가 0건이다. 경고가 뜨면 **허용하지 말고 차단**한 뒤 프로세스·목적지·시각을 적는다
   - 실패: 목적지와 그때 돌던 스캔을 적어 이슈로 남긴다. 그 스캔의 `run.log`·summary 의 "프록시가 막은 요청" 을 함께 첨부한다(질의값은 가려져 있다)
4. 결과 기록: 날짜, 런타임(Colima·Docker Desktop 버전), 플러그인 버전, 스캔별 결과를 [[구현 계획]] P4 메모에 적는다

> Docker 런타임의 VM 은 백그라운드에서 시간 동기화(NTP) 등을 할 수 있다. 스캔과 무관하게 스캔 전에도 보이는 연결이면 기준선으로 적고 구분한다.

## V2 탐지 정확도 (회귀 기준선)
| 대상 | 내용 | 기대 |
|---|---|---|
| 시크릿 픽스처 | 가짜 AWS 키·GitHub 토큰 형식 문자열을 커밋 후 삭제한 테스트 저장소 | Gitleaks git 모드가 히스토리에서 탐지, 원문 미노출 |
| SAST 픽스처 | 의도적 XSS/SQLi 코드 몇 줄 | Semgrep 탐지 |
| SCA 픽스처 | 알려진 취약 버전 고정 lockfile | OSV 탐지 |
| 모바일 | `debuggable`·cleartext 켠 내 테스트 빌드 — `tests/fixtures/app/`를 MobSF 이미지 안의 apktool·bundletool(APK·AAB)과 Xcode clang(IPA)으로 네트워크 없이 빌드 | MobSF·Gitleaks 탐지 — `tests/baseline/app-android.json`·`app-ios.json` |
| 웹 | 보안 헤더 없는 로컬 테스트 서버 | ZAP 탐지 |

결과를 `tests/baseline/*.json`으로 저장 → 업데이트 후 비교.
