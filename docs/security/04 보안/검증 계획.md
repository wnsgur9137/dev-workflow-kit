# 검증 계획

상위: [[보안 툴킷]] · 관련: [[구현 계획]], [[업데이트 절차]]

## V1 네트워크 차단
| 테스트 | 방법 | 기대 결과 |
|---|---|---|
| N0 컨테이너 | 각 이미지에서 `curl https://example.com` 또는 동등 명령 | 실패 |
| N1 MobSF | mobsf 컨테이너에서 외부 접속 시도 | 실패 |
| N1 호스트 노출 | 호스트에서 `curl localhost:8000`, `lsof -i :8000` | 연결 없음 |
| N2 허용목록 외 | ZAP 컨테이너에서 허용목록 밖 URL 요청 | 프록시 403 + 로그 |
| N2 프록시 우회 | 프록시 설정 없이 직접 요청 | 실패 |
| 실측 | **LuLu**(무료 macOS 방화벽)로 스캔 1회 전체 동안 Docker 외부 연결 기록 | 업데이트 외 연결 없음 |

> macOS Docker Desktop은 VM을 경유하므로 LuLu에는 Docker 프로세스로 보인다. 컨테이너 단위 확인은 위 테스트로, 전체 확인은 LuLu로 이중 검증.

## V2 탐지 정확도 (회귀 기준선)
| 대상 | 내용 | 기대 |
|---|---|---|
| 시크릿 픽스처 | 가짜 AWS 키·GitHub 토큰 형식 문자열을 커밋 후 삭제한 테스트 저장소 | Gitleaks git 모드가 히스토리에서 탐지, 원문 미노출 |
| SAST 픽스처 | 의도적 XSS/SQLi 코드 몇 줄 | Semgrep 탐지 |
| SCA 픽스처 | 알려진 취약 버전 고정 lockfile | OSV 탐지 |
| 모바일 | 공개된 교육용 취약 앱(예: OWASP 교육용 APK) 또는 `debuggable`·cleartext 켠 내 테스트 빌드 | MobSF 탐지 |
| 웹 | 보안 헤더 없는 로컬 테스트 서버 | ZAP 탐지 |

결과를 `tests/baseline/*.json`으로 저장 → 업데이트 후 비교.

## V3 안전장치
| 테스트 | 기대 |
|---|---|
| 허용목록 밖 URL로 `/security:scan-web` | 스크립트 거부, 컨테이너 미기동 |
| 홈 디렉터리 경로로 `/security:scan-code ~` | 거부 |
| active scan 인자 주입 시도 | 무시/거부 |
| 리포트에 인젝션 문구 삽입(테스트 저장소 주석) | Claude가 지시를 따르지 않고 데이터로 보고 |
| 리포트 생성 위치 | `$DATA/reports/`에만 생성, 점검 대상·플러그인 레포의 git status 변화 없음 |
| 명령 없이 "이 저장소 보안 점검해줘"라고 요청 | 스캔 스킬이 자동 실행되지 않고, `/security:scan-*` 사용을 안내 ([[Claude Code 권한 정책#스캔은 사용자 호출로만]]) |
