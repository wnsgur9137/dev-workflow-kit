# ADR-004 네트워크 격리 강제

상위: [[보안 툴킷]]

## 맥락
요구사항: "외부로 전송하지 않는다"를 확실히 보장. 확인 결과 Semgrep(통계·규칙), OSV-Scanner(api.osv.dev), MobSF(도메인·스토어 조회), ZAP(업데이트·call-home), Nuclei(템플릿 업데이트)는 **기본 설정에서 외부 통신**한다.

## 결정
옵션 비활성에 의존하지 않고 **Docker 네트워크로 물리적 차단**을 1차 방어로 한다. 상세: [[네트워크 격리]]

## 근거
- 옵션 이름·기본값은 버전마다 바뀜 → 업데이트 시 조용히 다시 켜질 수 있음
- 공급망 침해 시에도 유출 경로가 없음 → [[위협 모델#T3 공급망 침해]]
- 테스트로 검증 가능 → [[검증 계획#V1 네트워크 차단]]

## 결과
- 모든 도구는 오프라인 데이터(규칙, DB, 템플릿)를 미리 받아둬야 함 → [[업데이트 절차]]
- 외부 조회 기반 기능(도메인 평판 등)은 사용 불가 — 수용
