# 요구사항

상위: [[보안 툴킷]]

## 목적
개인 앱·웹 사이드 프로젝트의 보안 문제를 **Claude Code 세션 안에서** 점검하고, 결과를 Claude가 해석해 수정까지 이어지게 한다.

## 기능 요구사항 (FR)

| ID | 요구사항 | 관련 |
|---|---|---|
| FR-1 | 소스 코드의 취약 패턴(인젝션, XSS, 안전하지 않은 API 등) 탐지 | [[Semgrep]] |
| FR-2 | 소스·git 히스토리 내 하드코딩 시크릿 탐지 | [[Gitleaks]] |
| FR-3 | 의존성(npm, pub, Gradle, CocoaPods, SPM 등)의 알려진 CVE 탐지 | [[OSV-Scanner]] |
| FR-4 | APK/AAB/IPA 바이너리 정적분석 | [[MobSF]] |
| FR-5 | 로컬/스테이징 웹의 보안 헤더·쿠키·정보노출 점검 (공격 요청 없음) | [[OWASP ZAP]] |
| FR-6 | 모든 결과를 단일 포맷으로 정규화하고 요약본 생성 | [[리포트 포맷]] |
| FR-7 | Claude Code 슬래시 명령(스킬)으로 실행 | [[ADR-002 MCP 서버 대신 스킬]] |
| FR-9 | `dev-workflow-kit` 레포의 `security` 플러그인으로 배포, `/plugin` 명령으로 설치·업데이트 | [[ADR-006 플러그인 마켓플레이스 구조]] |
| FR-8 | 규칙·취약점 DB·이미지 갱신은 별도 명령으로만 수행 | [[업데이트 절차]] |

## 비기능 요구사항 (NFR)

| ID | 요구사항 | 근거 |
|---|---|---|
| NFR-1 | **무료**: 모든 구성요소는 무료 오픈소스. 유료 API 키 불필요 | 사용자 요구 |
| NFR-2 | **외부 전송 없음**: 스캔 단계에서 코드·바이너리·결과가 외부로 나가지 않음 (네트워크 차원에서 보장) | 사용자 요구, [[ADR-004 네트워크 격리 강제]] |
| NFR-3 | **역보안 문제 없음**: 툴킷 자체가 공격 표면·유출 경로가 되지 않음 | 사용자 요구, [[위협 모델]] |
| NFR-4 | **비파괴**: 실제 공격 페이로드 전송 금지 | [[ADR-005 Active Scan 금지]] |
| NFR-5 | **재현성**: 이미지·도구 버전 고정 | [[업데이트 절차]] |
| NFR-6 | **로컬 실행**: macOS + Docker에서 동작 | 환경 |
| NFR-7 | **데이터 분리**: 리포트·DB·설정은 플러그인 폴더 밖에 저장 (플러그인 업데이트로 사라지지 않음) | [[ADR-006 플러그인 마켓플레이스 구조]] |

## 범위 밖 (Out of Scope)
- 자율 침투테스트 / 익스플로잇 → [[ADR-001 Artex 제외]]
- 모바일 **동적** 분석 (에뮬레이터·Frida) — 추후 검토, [[미결정 사항]]
- 운영(production) 환경 대상 점검
- CI/CD 연동 — 로컬 안정화 후 검토

## 명시적 한계
- Claude Code는 분석을 위해 **Claude가 읽은 코드와 요약 리포트를 Anthropic으로 전송**한다. 이는 Claude를 쓰는 한 피할 수 없으며, [[시크릿 처리]]로 시크릿 원문 노출을 막는다.
