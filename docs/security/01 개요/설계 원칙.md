# 설계 원칙

상위: [[보안 툴킷]]

1. **역할 분리: 탐지는 스캐너, 판단은 Claude**
   스캐너는 규칙 기반으로 결정적으로 동작하고 스스로 공격을 결정하지 않는다. Claude는 결과 파일만 읽고 해석·오탐 판정·수정 제안을 한다. → [[ADR-001 Artex 제외]]

2. **설정이 아니라 네트워크로 보장한다**
   "텔레메트리 끄기" 옵션은 버전마다 바뀔 수 있다. 스캔 컨테이너는 `--network none` 또는 `internal` 네트워크로 **물리적으로** 외부 통신을 막고, 옵션은 2차 방어로만 쓴다. → [[네트워크 격리]]

3. **상시 서버 최소화**
   필요할 때만 켜고, 끝나면 내린다. 상시 MCP 서버를 두지 않는다. → [[ADR-002 MCP 서버 대신 스킬]]

4. **읽기 전용 입력, 쓰기는 리포트 폴더만**
   분석 대상은 `:ro` 마운트. 컨테이너가 쓸 수 있는 곳은 `$DATA/reports/<run-id>/` 하나 (경로 표기 → [[아키텍처#경로 표기]]).

5. **시크릿 원문은 Claude 컨텍스트에 들어가지 않는다**
   `--redact`, 리포트 정규화 단계의 마스킹. → [[시크릿 처리]]

6. **스캔 결과는 신뢰하지 않는 데이터다**
   APK 문자열, 웹 응답 등 공격자가 통제 가능한 내용이 포함될 수 있다. Claude는 이를 지시가 아닌 데이터로 다룬다. → [[위협 모델#T5 프롬프트 인젝션]]

7. **버전 고정 + 지연 도입**
   이미지 digest 고정, 새 버전은 공개 후 일정 기간(기본 7일) 지난 뒤 도입. → [[업데이트 절차]], [[ADR-003 Trivy 제외]]

8. **비파괴**
   웹 점검은 passive만. 공격성 템플릿·active scan 금지. → [[ADR-005 Active Scan 금지]]

9. **허용목록(allowlist) 이중 강제**
   웹 대상은 스크립트 검사 + 이그레스 프록시 두 곳에서 강제한다.

10. **스캔은 사용자가 호출할 때만**
   Claude가 대화 맥락으로 스캔 스킬을 자동 실행하지 않도록 막는다. → [[Claude Code 권한 정책#스캔은 사용자 호출로만]]
