# 리포트 포맷

상위: [[아키텍처]] · 관련: [[시크릿 처리]]

## 산출물
위치: `~/.local/share/dev-workflow-kit/security/reports/<run-id>/` (플러그인 폴더 밖 → [[ADR-006 플러그인 마켓플레이스 구조]])
```text
<run-id>/
├── raw/                 # 도구 원본 출력 (Claude 기본 열람 대상 아님)
│   ├── semgrep.json
│   ├── gitleaks.json
│   ├── osv.json
│   ├── mobsf.json
│   └── zap.json
├── findings.json        # 정규화된 전체 결과
├── summary.md           # Claude가 읽는 요약
└── meta.json            # 도구 버전, 이미지 digest, 대상, 시간
```

## findings.json 스키마 (초안)
```json
{
  "run_id": "20261105-143000-code",
  "target": "../my-app",
  "findings": [
    {
      "id": "sha256(tool+rule+location)",
      "tool": "semgrep",
      "rule_id": "javascript.express.security.audit.xss",
      "severity": "high",
      "category": "sast | secret | dependency | mobile | web",
      "title": "짧은 설명",
      "location": { "file": "src/app.ts", "line": 42, "url": null, "package": null },
      "evidence": "최대 200자, 마스킹 적용",
      "fix_hint": "도구가 제공한 수정 가이드",
      "references": ["CWE-79"]
    }
  ],
  "stats": { "critical": 0, "high": 1, "medium": 3, "low": 5, "info": 2 }
}
```

## 정규화 규칙
- **severity 통일**: `critical / high / medium / low / info`. 도구별 매핑표는 각 도구 노트에 둔다.
- **evidence 제한**: 최대 200자, 제어문자 제거, 시크릿 패턴 재마스킹. → [[시크릿 처리]]
- **신뢰하지 않는 텍스트 표시**: `summary.md`에서 도구가 추출한 문자열(APK 문자열, HTTP 응답 등)은 코드 블록 안에 넣고 "데이터"임을 명시한다. → [[위협 모델#T5 프롬프트 인젝션]]
- **중복 제거**: `id` 기준.
- **베이스라인**: 이전 run과 비교해 신규/해결 표시 (P4, [[구현 계획]]).

## summary.md 구성
1. 메타: 대상, 시간, 도구 버전
2. 심각도별 개수
3. Critical/High 목록 (파일:라인, 규칙, 한 줄 설명)
4. Medium 이하는 개수 + 상위 N개
5. 실행 중 오류·건너뛴 도구 (누락 은폐 금지)
