# ADR-007 레포 이름과 커맨드 정리

상위: [[Home]] · 계획: [[레포 통합 계획]]

## 맥락
`pr-review-command`는 PR 리뷰만 가리키지만 실제로는 커밋·PR 생성·리뷰·반영·파이프라인을 포함하고, 보안 툴킷까지 추가된다.

## 결정
1. 레포·로컬 폴더 이름: **`dev-workflow-kit`**
   - 브랜드 이름(Claude)을 넣지 않은 중립적 이름 (후보 `claude-code-devkit`, `claude-devkit` 대신 선택)
2. `/ship` → **`/pipeline`** 으로 교체 (로컬에서 발전한 14단계 버전, `--no-issue`가 기존 `/ship` 역할 대체)
3. `/create-pr`: 로컬·레포 변경 모두 병합
4. `/apply-review`: 레포(PR #5) 버전 기준
5. 보안 커맨드: `/security:scan-code`, `/security:scan-app`, `/security:scan-web` (내장 `/security-review`와 구분)

## 결과
- GitHub 이름 변경 시 이전 URL은 자동 리다이렉트되지만, 로컬 remote는 갱신
- 문서·템플릿 내 "Review Command" 표기 변경 필요
- `/ship`을 쓰던 사용자는 `/pipeline --no-issue`로 이동 → README에 안내
